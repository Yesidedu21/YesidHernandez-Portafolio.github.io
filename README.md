## Sobre este portafolio

Este es mi portafolio profesional. En él resumo quién soy, qué busco, mi formación, mis habilidades y los proyectos que he desarrollado, para que cualquier reclutador o equipo técnico conozca mi perfil de un vistazo.

Lo construí con **HTML, CSS y JavaScript puro**, sin frameworks, con un diseño oscuro, responsive y accesible.

## Quién soy y qué busco

Soy Ingeniero de Sistemas y desarrollador Full Stack especializado en el ecosistema Java. Construyo backends con Spring Boot, JPA y Spring Security, y los conecto con interfaces web funcionales, siguiendo patrones como MVC, DTO y arquitectura por capas.

Busco mi próxima oportunidad como **desarrollador Full Stack Java**, en un equipo donde pueda aportar desde el primer día, aprender de profesionales con experiencia y seguir creciendo hacia arquitecturas más escalables.
